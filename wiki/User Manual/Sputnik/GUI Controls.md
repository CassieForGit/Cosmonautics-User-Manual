## GUI Controls

The Sputnik's main way of programming is via Nodes and Wires. Easy, Quick and Intuitive.

[This video](https://www.youtube.com/watch?v=qHK7vh4MuhY) explains very well the Sputnik if you prefer guides in video format or need visual aid.

if you Interact with the sputnik, you'll open it's Graph. Empty.

<img src="/wiki/images/Empty Sputnik Interface.png">  


<p style="font-size=75%;"> Note that results may and will vary between new and old versions. </p>

The wiggly line represents your path. It alone means that you are on root, that's normal.

To add a node, simply press RMB and a pop-up will show up. It shows a list of all built-in nodes complete with color-coded categories. It is scrollable.

Press a node name (eg. Constant in Math) to add it.
There are 14 Categories which have one or more nodes.

To connect two nodes, simply drag from an output point on the right of a node to start a wire, and then connect it to an input node, at the left of a node. Don't forget they are color-coded, with green meaning a number value (or boolean value, however they are mixed together) and yellow meaning a string value.



To see how to use of some nodes of categories, please review [Categories of Nodes](/wiki/User%20Manual/Sputnik/CategoriesofNodes.md).

To see some basic nodes, please review [Basic Nodes](/wiki/User%20Manual/Sputnik/BNodes.md).
