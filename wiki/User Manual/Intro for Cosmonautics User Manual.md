## Intro for the Manual

<img src="/wiki/images/User Manual Logo.png">

Hello there, I am Cassie, I am the founder of the Cosmonautics User Manual. This project is pointed towards teaching new players how to play the game (Especially with the Flight Programs!) and to make old players know things in a better, efficient way.

At the time of writing (Before the wiki was within the mod itself) the way you can help and note missing or incorrect things, is by opening an issue on github. The Repository of the wiki is CassieForGit/Cosmonautics-User-Manual.

In [Manual Lobby](/wiki/User%20Manual/Manual%20Lobby.md), you can access all of the documentation you might need.
